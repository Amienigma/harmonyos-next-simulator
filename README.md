# HarmonyOS NEXT Simulator

A phone-style HarmonyOS NEXT simulator in a single, self-contained `index.html` (no build step, no dependencies, no API keys).

**Live:** https://temporary-racing-cove-jvd9gua.vercel.app

## How to use
- **Tap an icon** to open an app: Calculator, Notes (saved in your browser), Settings, plus preview placeholders.
- **Swipe down from the top-right** to open the Control Panel (Wi-Fi, Bluetooth, Airplane, Dark mode, brightness, volume, Super Device audio).
- **Swipe down from the top-left** for Notifications. Tap one to dismiss it.
- **Swipe left/right** on the home screen to change pages.
- **Swipe up or tap the bottom bar** (or press `Esc`) to go home.

Mouse drags work like swipes on desktop.

## Run locally
Open `index.html` in any modern browser, or serve the folder with any static server.
